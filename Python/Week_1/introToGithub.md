1. What is Git, what is Github, and what is the difference between the two?
- Git is a control system that can track your codes. 
- Github is a remote that can help collab and share with people
- The difference between the two is that Github is a website that can save the projects that are made. While Git is a platform to control the codes 
2. What is the difference between a local repository and a remote repository?
- local repository is when the repository is on your system. While the Remote repository is on the cloud
3. What does the push command do in Git?
- Push is a way to upload local changes to the remote in Git.
4. What does the commit command do in Git?
- Commit saves the changes from the local side.
5. What is Github Desktop, & why are we using it?
- Github Desktop is desktop app that lets you to work with Git and Github without using Git commands.
